## Maggies Tanks 2026.11.09.3 — Menu on Shopdy's platform pages (fix)
### Fixed
- `/contact` (and the other pages Shopdy renders inside the theme's header / footer: verification, order list, order
  support, cancel order, change variant, tracking result…): the menu button did nothing. Shopdy loads only
  `assets/js/theme.js` there (`render-theme-chrome.ts` → `resolveThemeJsPath`), the theme ships `core.js` + `ui.js`, so
  no theme script ran. New `assets/js/theme.js`: a loader that adds core.js then ui.js (in order, once); core.js
  already reads the platform's `#sf-chrome-config`. Theme pages never load it. Checked on the live /contact,
  /verification and /cancel-order with the file injected: menu opens / closes, no page error.
